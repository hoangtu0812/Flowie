# thinking-orbs (vendored)

This package is a source snapshot of
[Jakub Antalik's thinking-orbs](https://github.com/Jakubantalik/thinking-orbs)
version 0.3.1, retained under its MIT license in `LICENSE`.

It is vendored so Flowie's production build does not need to retrieve a visual
dependency from a public registry. Update this package only by replacing it
with a reviewed upstream release and preserving its license.
