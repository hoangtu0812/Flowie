# Flowie web

Next.js 15 web client of Flowie. Setup, commands and deployment are in the
[root README](../../README.md); the code map for contributors and agents is in
[AI_GUIDE.md](./AI_GUIDE.md).

```shell
pnpm install
pnpm --filter @flowie/web dev
```

The UI started from the MIT-licensed [ln-dev7/circle](https://github.com/ln-dev7/circle)
template; see [LICENSE.md](../../LICENSE.md).
